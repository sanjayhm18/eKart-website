# eKart — Full Frontend E-commerce Demo

Open `index.html` directly in Chrome/Edge/Firefox.

Included:
- Responsive Amazon/Flipkart-inspired marketplace layout
- Search and category filtering
- Sorting by price/rating
- Product detail modal
- Wishlist
- Cart quantity controls and totals
- Login/register demo
- Checkout form with delivery/payment selection
- Order confirmation and order history
- localStorage persistence
- Mobile responsive UI

This is a frontend/demo implementation. Real authentication, database, inventory, shipping APIs, payment gateway, admin panel and production security require a backend.
